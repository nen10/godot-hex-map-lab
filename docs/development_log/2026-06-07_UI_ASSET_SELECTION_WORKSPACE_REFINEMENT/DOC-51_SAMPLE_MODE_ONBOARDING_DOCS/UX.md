# DOC-51 UX

## User Goal

New users should understand samples as an onboarding path without mistaking them for production defaults.

## Documentation Flow

- The first-run `Learn with bundled samples` action routes to Settings / Samples.
- Sample mode can reveal bundled learning candidates in main selectors.
- Project assets remain primary when selected.
- Duplicate sample catalog to project copies the catalog, texture, and scene dependencies.
- Production workflow remains project asset selection.

## Non-goals

- Do not add analog tests.
- Do not make sample mode the default.
- Do not duplicate package integrity details beyond linking to package docs.
