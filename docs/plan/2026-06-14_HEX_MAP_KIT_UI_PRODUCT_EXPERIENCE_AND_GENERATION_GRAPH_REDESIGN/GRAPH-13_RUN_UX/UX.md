# GRAPH-13 UX

## 達成したい体験
- 画面上部の `[Generate]`(N=1) が一番目立つ。param を変えて押す→結果が見える、が最初の体験。
- 変えた node の下流だけ再生成され、**待ち時間が短い**。
- 重い生成は **cancel** でき、進捗が見える。
- 失敗したら **どの node が原因か**色で分かる。
- N 枚生成・randomize は下方にあり、**やりたい人だけ**触る。

## 避ける体験
- 毎回全 graph を再生成して待たされる。
- 失敗理由・場所が分からない。
- 初手で N 枚生成の重い UI が前面に出る。

## UX Candidate Matrix
| 論点 | 候補 | 採用 | 理由 |
|---|---|---|---|
| 進捗 | A: busy + cancel / B: ブロッキング | **A** | 重い生成を握れる |
| 失敗表示 | A: node 強調 + 理由 / B: ダイアログのみ | **A** | 場所が即分かる |
