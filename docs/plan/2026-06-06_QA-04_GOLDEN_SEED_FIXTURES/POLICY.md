## Decisions

- Golden seed fixtures live under `docs/test/fixtures/` so they are reviewable documentation as well as test input.
- Fixture expectations compare stable generation data: summary, numeric score, wall keys, and ASCII preview rows.
- The score is deterministic and intentionally simple: floor count, wall count, connectivity, and toric cyclic size are combined by the test helper. It is a regression guard, not a content quality metric.
- Preview artifacts are text rows generated by `HexMapDebug.render_ascii()`. They are not treated as a visual screenshot assertion.
- Fixture changes must be reviewed as generator behavior changes. The test should fail on drift instead of silently accepting new output.

## Compatibility

- No saved resource schema changes.
- No runtime or editor API changes.
- Existing generator tests remain source of behavioral truth; QA-04 adds compact fixture guardrails for selected seeds.
