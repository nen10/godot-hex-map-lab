# INFO-72 Export Terminology Decision Policy

Date: 2026-06-08

## Decisions

- Use `Runtime Handoff` for the active Export tab workflow.
- Do not use `Export` to mean authoring document save.
- Do not place package build controls in the normal editor Export tab.
- Do not place debug report creation in the normal editor Export tab.
- Keep `Data Export` as backlog for JSON/CSV/external-format work.

## Non-goals

- Do not implement JSON/CSV export.
- Do not add package build UI.
- Do not move debug report support into Export.
- Do not add an analog test.
