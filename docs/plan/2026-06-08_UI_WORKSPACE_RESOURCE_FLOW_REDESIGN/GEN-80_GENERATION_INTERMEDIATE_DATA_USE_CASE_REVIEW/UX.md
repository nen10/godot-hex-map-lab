# GEN-80 Generation Intermediate Data Use-Case Review UX

Date: 2026-06-08

## User goal

A level designer should understand which generation artifacts are immediate Generate/QA feedback, which should become Resource/API work, and which are graph-editor research.

## Flow

1. Generate a preview.
2. Optionally compare seeds in QA.
3. Apply or promote a result into the Level Document.
4. Avoid expanding the Generate tab into a graph editor until the Resource model is decided.

## Visible contract

- Immediate UI remains preview, apply, validation, progress, and QA comparison.
- Intermediate data persistence is a model-design task, not another control group in Generate.
- Graph editor work remains research until Generation Profile / Result / Document ownership is specified.
