# INFO-70 Resource Purpose Tooltips Policy

Date: 2026-06-08

## Decisions

- Resource purpose belongs in tooltip/help text, not long inline row text.
- Required type guidance must be present on resource row tooltips.
- Flexible Resource slots must keep the reason they cannot use a concrete type filter yet.
- TileSet purpose is owned by Catalog detail until TileSet becomes a first-class workspace asset slot.

## Non-goals

- Do not add an analog test.
- Do not add new asset slots only to satisfy tooltip coverage.
- Do not reintroduce path text as primary UI.
