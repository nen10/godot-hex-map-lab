# DOC-90 Workspace UI Manual Update UX

Date: 2026-06-08

## User goal

A first-time level designer should be able to read the manuals and understand the current Workspace flow without seeing the old `Document` tab terminology.

## Flow

1. Select a `HexTileMap` in the Scene tree.
2. Use `Resources` to create or select the Level Document and node-owned resources.
3. Use `Catalog`, `Paint`, `Layers`, `Validate`, `QA`, and `Export` for task-specific work.
4. Use `Generate` output target options to choose between preview and applying into the selected document.
5. Use `Settings` samples only for learning or duplicating assets into project-owned resources.

## Visible contract

- `Resources` is the starting point for project asset ownership.
- Selected `HexTileMap` auto-link is the normal context path.
- Samples are learning assets, not production defaults.
- Runtime Handoff is distinct from saving a Level Document.
