# DOC-NEXT-90 UX Notes

The documentation now presents `Hex Map Workspace` as a set of task screens with explicit production intent:
`Resources`, `Catalog`, `Layers`, `Paint`, `Validate`, `QA`, `Generate`, `Export`, `Settings`.

Docs now state that:
- Export is runtime handoff, not package build.
- Debug overlay/reporting is separate from normal gameplay rendering and follows Validate/debug-report flow.
- Bundled samples are learning assets only and must not silently satisfy production completion.
- Fallback/override boundaries are traceable via the fallback ledger.
