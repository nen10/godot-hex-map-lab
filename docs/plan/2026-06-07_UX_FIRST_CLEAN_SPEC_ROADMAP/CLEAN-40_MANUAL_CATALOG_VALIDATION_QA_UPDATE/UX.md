# CLEAN-40 Manual Catalog Validation QA Update UX

## Goal

Make the public manuals describe the current clean editor workflow by user goal instead of by historical implementation paths.

## User Contract

- A level author can find document setup, catalog selection, object placement, layer stack, validation, generation QA, and debug-report workflows without reading internal fallback details.
- Resource picker and FileDialog selection are the documented normal paths.
- Catalog key authoring is the normal tile/object/overlay vocabulary.
- Validation and Copy Debug Report are explained as authoring feedback and support workflows.
- No new analog test files are introduced for this documentation pass.

## Non-Goals

- CLEAN-41 owns the deeper public API vocabulary pass.
- CLEAN-51 owns broader canonical resource test coverage.
- Analog test redesign remains deferred during UI rework.
