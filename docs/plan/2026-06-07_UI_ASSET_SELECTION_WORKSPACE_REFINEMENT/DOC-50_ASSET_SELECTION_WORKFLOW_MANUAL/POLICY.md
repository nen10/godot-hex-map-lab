# DOC-50 Policy

## Requirement

Manuals must describe project asset selection as the main editor workflow. Samples are learning/onboarding assets and may be duplicated to project assets before use in production.

## Required Docs

- `README.md`
- `docs/manual/MANUAL_EDITOR_PLUGIN.md`
- `docs/manual/MANUAL_WORKFLOW.md`
- `docs/manual/MANUAL_PACKAGE.md`

## Boundaries

- No new analog test files.
- Sample package integrity remains in package docs/tests.
- Normal setup must not rely on `Use Sample Tiles` or silent sample fallback.
