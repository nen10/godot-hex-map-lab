# DOC-50 UX

## User Goal

The manuals should teach the production workflow first: create or select project assets, then use samples only as learning material.

## Documentation Flow

- Start in Hex Map Workspace with project asset slots.
- Create/select a Level Document, Tile Catalog, TileSet, Object Database, Label Database, Generation Profile, Validation Rule Suite, Export Profile, and export destination through Resource pickers/FileDialogs.
- Use Paint and Generate through catalog keys and definition keys.
- Use Settings / Samples for learning and optional duplication into project assets.

## Non-goals

- Do not add analog tests.
- Do not present `Use Sample Tiles` as normal setup.
- Do not document raw path text, numeric fallback, or raw JSON as primary authoring workflows.
