# TEST-40 UX

## User Goal

Feature-screen completion must prove the production project-asset workflow, not only the bundled sample learning path.

## Normal Flow

- The workspace starts with sample mode OFF.
- Document, Catalog, Layers, Paint/Object/Label, Validate, QA, and Export screens show project asset slots or missing-project-asset validation state.
- A screen reaches completion by selecting, creating, saving, or validating project-owned assets.
- Bundled sample visibility is a Settings / Samples learning choice and does not complete production feature screens by default.

## Non-goals

- Do not add new analog tests.
- Do not remove sample learning/package integrity coverage.
- Do not make feature tests depend on private widget names.
